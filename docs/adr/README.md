# Architecture Decision Records

This directory contains accepted decisions for the BGLA Governed Agent Knowledge Architecture.

| ADR | Decision | Status |
|---|---|---|
| [0001](0001-bgla-knowledge-architecture.md) | Four-tier architecture and cross-cutting governance control plane | Accepted; target state implemented incrementally |
| [0002](0002-security-context-and-authorization.md) | Trusted SecurityContext and authorization boundary | Accepted |
| [0003](0003-provenance-and-lifecycle-invalidation.md) | Provenance and deny-first lifecycle invalidation | Accepted |
| [0004](0004-agent-memory-governance.md) | Governed agent memory and retention | Accepted |

An accepted ADR records the architectural decision. It does not imply that every capability described by that decision is already implemented or production-certified. See the [architecture index](../architecture/README.md) and [implementation roadmap](../architecture/implementation-roadmap.md).
